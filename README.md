**Mi Proyecto Web**

**Proyecto web básico desarrollado con HTML para aprender a utilizar Git y GitHub, trabajar con ramas independientes y documentar los cambios realizados.**



**Tabla de contenidos**

* **Instalación**
* **Estructura del proyecto**
* **Mejoras implementadas**
* **Tecnologías utilizadas**



**Instalación**

1. **Clonar el repositorio de GitHub.**
2. **Abrir la carpeta del proyecto.**
3. **Abrir el archivo index.html con cualquier navegador web.**



**Estructura del proyecto**

* **index.html: página principal del sitio web.**
* **.gitignore: archivo que indica qué archivos y carpetas debe ignorar Git.**
* **README.md: documentación del proyecto.**



**Mejoras implementadas**

* **Menú de navegación: incorpora enlaces internos para desplazarse por las diferentes secciones de la página.**
* **Tabla de horario: muestra un horario de estudio organizado en una tabla HTML.**



**Tecnologías utilizadas**

* **HTML5.**
* **Git.**
* **GitHub.**
* **Markdown.**
